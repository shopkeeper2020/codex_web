# codex_web

[简体中文](./README.md) | English

`codex_web` is an in-development Codex web client. The goal is to provide a browser-based experience close to Codex Desktop, while exploring realtime synchronization with Codex Desktop and the VS Code extension.

## Status

The project is preparing for its first public release. Source code is not available yet. Version **0.1.2605311** is expected to be released on **May 31, 2026**.

This public repository currently serves as a landing page for the project direction, release plan, and future documentation.

## Goals

- Recreate the main Codex Desktop interface and interaction model in the browser
- Support both desktop and mobile browsers
- Support projects, threads, streaming conversations, and a Desktop-like composer
- Explore three-way synchronization with Codex Desktop and the VS Code extension
- Keep the frontend and backend architecture clean and maintainable

## Planned Tech Stack

- React
- TypeScript
- Vite
- Fastify
- SQLite / Drizzle
- Playwright
- pnpm workspace

## Use Case

`codex_web` is intended for users who want to access local Codex workflows from a browser, phone, or LAN device. It is not designed as a hosted cloud service; it focuses on local execution, local resource access, and personal workflow extension.
